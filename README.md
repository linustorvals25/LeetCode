# LeetCode Solutions

Repositorio dedicado a la resolución y análisis de problemas algorítmicos de **LeetCode**, con especial énfasis en **Python** y **C++**.

El objetivo principal es fortalecer las habilidades de programación, desarrollar el pensamiento algorítmico y estudiar diferentes estructuras de datos y algoritmos mediante la resolución constante de problemas.

---

## LeetCode

[LeetCode](https://leetcode.com/) es una plataforma que permite practicar programación mediante problemas relacionados con algoritmos, estructuras de datos y resolución de problemas computacionales.

Este repositorio funciona como un espacio de aprendizaje y documentación donde se recopilan soluciones, se analizan diferentes enfoques y se estudian sus características.

### Objetivos

- Practicar y mejorar las habilidades de programación.
- Desarrollar el pensamiento lógico y la capacidad de resolver problemas.
- Comprender y aplicar estructuras de datos y algoritmos.
- Analizar la complejidad temporal y espacial de las soluciones mediante notación Big O.
- Comparar diferentes implementaciones de un mismo problema.
- Mejorar progresivamente la calidad, eficiencia y legibilidad del código.
- Familiarizarse con las herramientas y características de Python y C++.

---

## Lenguajes de programación

Los lenguajes principales utilizados en este repositorio son **Python** y **C++**. Ambos permiten abordar los problemas desde perspectivas diferentes y ofrecen herramientas útiles para comprender los fundamentos de la programación.

### Python

Se utiliza **Python** como lenguaje principal debido a su sintaxis sencilla, legibilidad y versatilidad.

Su alto nivel de abstracción permite concentrarse en la lógica de los algoritmos sin dedicar demasiado esfuerzo a detalles relacionados con la gestión de memoria o la sintaxis del lenguaje.

Además, Python proporciona estructuras de datos y herramientas integradas que facilitan la implementación de diferentes soluciones.

Algunos de los temas que se practican son:

- Tipos de datos y estructuras integradas (`list`, `dict`, `set`, `tuple`).
- Comprensiones de listas y diccionarios.
- Funciones, módulos y programación orientada a objetos.
- Recursividad y backtracking.
- Manipulación de cadenas.
- Listas enlazadas, pilas, colas y árboles.
- Diccionarios y conjuntos para implementar soluciones eficientes.
- Algoritmos de búsqueda y ordenamiento.
- Programación dinámica y técnicas de optimización.

### C++

Se utiliza **C++** para complementar el aprendizaje y profundizar en los fundamentos de la programación de bajo nivel y la eficiencia de los algoritmos.

A diferencia de Python, C++ permite un mayor control sobre la memoria y los recursos del sistema. También proporciona herramientas de la biblioteca estándar (STL) que facilitan la implementación de estructuras de datos y algoritmos.

Algunos de los temas que se practican son:

- Tipos de datos, referencias y punteros.
- Gestión de memoria.
- Arreglos y cadenas.
- Contenedores de la STL (`vector`, `list`, `stack`, `queue`, `unordered_map`, `set`, entre otros).
- Iteradores y algoritmos de la STL.
- Recursividad y backtracking.
- Árboles, grafos y estructuras de datos.
- Algoritmos de búsqueda y ordenamiento.
- Programación dinámica.
